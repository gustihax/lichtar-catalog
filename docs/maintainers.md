# Нотатки для супровідників каталогу

> Цей файл і весь каталог живуть в **окремому репозиторії** (`lichtar-catalog`), не в репозиторії самої програми. Інакше свіжий патч затьмарив би останній реліз програми, і її самооновлення зламалося б. Теги програми мають вигляд `v0.2.0`, їх каталог ігнорує.

1. На GitHub відкрийте **Releases → Draft a new release**.
2. Тег напишіть так: `id-гри-v1.4.3`. Наприклад, `blood-west-v1.4.3`. `id` береться з `catalog.json`.
3. Прикріпіть zip-архів із файлами патча. Шляхи всередині архіву мають повторювати теки гри.
4. В описі напишіть, що виправлено, по одному рядку з дефісом:
   ```
   - Виправлено назви предметів у торговця
   - Дошліфовано діалоги у фіналі
   збірка: 1234567
   ```
   Останній рядок необов'язковий: це збірка Steam, на якій ви перевіряли патч.
5. Натисніть **Publish release**. За хвилину в `catalog.json` з'являться нова версія, посилання, SHA256, розмір і запис в історії змін. Лончер у всіх підхопить це сам.

**Перевірити, не чіпаючи каталог.** Поставте галочку «pre-release»: такий реліз каталог не змінює.

**Якщо щось не вийшло.** Відкрийте вкладку **Actions**: червона позначка й журнал скажуть, що не так (немає гри в каталозі, немає архіву, неправильний тег).

## Нова гра

Поки що додайте блок у масив `games` у `catalog.json`:

```json
{
  "id": "blood-west",
  "name": "Blood West",
  "studio": "Hyperstrange",
  "hue": 25,
  "steam_appid": 1587130,
  "exe": ["BloodWest.exe"],
  "folders": ["Blood West"],
  "version": "", "size": "", "url": "", "sha256": "",
  "log": []
}
```

`hue` це колір гри в інтерфейсі, від 0 до 360. `exe` потрібен, щоб Ліхтар упізнавав гру в теці (піратка чи ліцензія, неважливо). `folders` це можливі назви теки гри.

## Як заповнити дані гри

1. На ПК з встановленою грою: `python tools/inspect_game.py "ШЛЯХ\до\гри"`. Скрипт підкаже `exe`, назву теки, `steam_appid` і збірку (працює і з піратськими копіями).
2. Вставте отриманий запис у масив `games` у `catalog.json`, впишіть `studio` і видаліть поле `_note`.
3. Випустіть патч (розділ вище), потім перевірте: `python tools/validate_catalog.py catalog.json --release --online`. Перевірка завантажить архіви й звірить SHA256. У репозиторії каталогу вона також запускається сама при кожній зміні `catalog.json` (вкладка Actions).
4. Перед збіркою програми, з теки програми `lichtar`: `python tools\sync_bundled.py ..\lichtar-catalog\catalog.json src\index.html`, щоб вбудований резервний каталог збігався з опублікованим.

У релізному каталозі лишайте лише ігри з готовими патчами: валідатор з `--release` вважає запис без патча помилкою.

## Підключення до лончера

У `index.html` впишіть адресу каталогу:

```js
const CATALOG_URL = 'https://raw.githubusercontent.com/ВАШ_НІК/ВАШ_РЕПОЗИТОРІЙ/main/catalog.json';
```
