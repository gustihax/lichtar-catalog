# Каталог Ліхтаря

Тут зберігається список українізаторів, який показує [Ліхтар](https://github.com/gustihax/lichtar): ігри, версії патчів, історія змін і новини. Самі патчі лежать у [Releases](../../releases).

Сюди не треба нічого завантажувати вручну. Ліхтар сам читає `catalog.json` і оновлює українізатори в один клік.

## Як отримати українізатор

1. Завантажте Ліхтар зі [сторінки релізів програми](https://github.com/gustihax/lichtar/releases/latest).
2. Оберіть гру в каталозі й натисніть «Встановити».

## Знайшли помилку або хочете запропонувати гру

Напишіть у [Issues програми](https://github.com/gustihax/lichtar/issues) або через кнопку «Підтримка» в Ліхтарі.

Нотатки для тих, хто веде каталог: [docs/maintainers.md](docs/maintainers.md).
